**Inventory Management Application (Android)**

This project is a Java-based Android application designed to manage inventory data, track item counts, and notify users when stock reaches zero. The application includes user authentication, persistent data storage, and automated SMS notifications, demonstrating mobile development and database integration.

**Overview**

This application allows users to create an account, log in, and manage inventory items. Users can add, update, and delete inventory entries, track item quantities, and receive notifications when stock levels are depleted.

The project demonstrates mobile application development, local database management using SQLite, and the implementation of real-time inventory monitoring features.

 

**Technologies Used**

- Language: Java
- IDE: Android Studio
- Platform: Android SDK
- Database: SQLite (local on-device database)
 

**Key Features**

- User account creation and login system
- Add, update, and delete inventory items (CRUD operations)
- Track item quantities in real time
- Persistent local storage using SQLite
- SMS notifications triggered when inventory reaches zero
- User-friendly interface for managing inventory data

**Database Design**

The application uses SQLite to store all data locally on the device.

Data stored includes:

- User account information
- Inventory items
- Item quantities
  
The database supports full CRUD operations, enabling real-time updates and persistence.

 

**How to Run the Project**

1. Install Android Studio
2. Clone or download the repository
3. Open the project in Android Studio
4. Set up an Android emulator or connect a physical device
5. Build and run the application
  
Note: SMS functionality may require proper device permissions and may not function fully on all emulators.
